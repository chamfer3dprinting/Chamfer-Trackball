# Chamfer Trackball v1.0.5

2026-10-28

- Less delay when using the trackball buttons: the mouse listener answers Windows straight away and a separate fast thread sends the orbit, pan and zoom movement, so a busy PC no longer holds up the pointer.
- Orbit and pan start after a smaller roll of the ball.
- The Try it cube updates with every screen frame instead of about 30 times a second.
