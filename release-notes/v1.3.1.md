# Chamfer Trackball v1.3.1

2026-10-29

- Steadier 3D modelling: the ball now does only what the top-right button chose (orbit → pan → zoom). Circles no longer switch it to zoom, so orbiting along curves never stutters or zooms by mistake.
- The view stops sooner when you stop rolling (shorter glide). You can still lengthen it on Speed & direction.
- The pointer no longer jumps to the middle each time you start rolling again; it only moves if it's near a toolbar or the edge.
- Short pauses no longer restart the move, and long spins re-grip the model less often, so there are fewer hiccups and no accidental clicks.
