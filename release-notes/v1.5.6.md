- Editable application source, tests and repeatable Windows builds now live in this repository.
- Normal left/right clicks and both wheels are the default. No Windows-wide button swap.
- Default held controls: Shift = orbit; Ctrl+Shift = pan with simultaneous wheel zoom; Alt + ball = aligned-view snapping; backtick + ball = navigation, with Alt for height.
- All five held-key bindings are editable and persisted; Ctrl by itself remains normal.
- Draft and complete combinations save immediately and survive restart.
- Included Blender and Fusion integrations provide camera data and a cursor/selection pivot, 26 aligned snap directions, camera roll, pan/zoom and navigation. Install from CAD apps inside the executable, then enable in the CAD app.
- Other apps use editable orbit/pan/zoom mouse-emulation profiles; custom 3D apps can be added. Native snapping/pivot/navigation require an adapter.
- The M512's normal mouse input supplies X/Y, with a wheel for the independent third control. This update does not claim to add a physical twist sensor.
- The build runs regression checks and an actual embedded-interface smoke test. Physical M512 behavior and the integrations in installed CAD applications still require owner testing.
