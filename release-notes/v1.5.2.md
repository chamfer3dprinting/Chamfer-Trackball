# Chamfer Trackball v1.5.2

2026-10-29

- New default in 3D modelling: btn1 = left click, btn2 = right click, btn3 = pan, btn4 = orbit, btn3 + btn4 lit = zoom in / out with the ball (roll up = in, down = out).
- Unlight one of btn3 / btn4 while zooming and you're back to that button's pan or orbit.
- btn2 stays a right click in every mode (no Snap view by default; you can still add it).
