# Input routing correction — 2026-10-30

The owner reported that orbit, pan and circle zoom all failed in Chamfer Studio.
The installed Admin v1.5.8 showed a device-input timeout. The selected 3D program
also had circle zoom off and Back set to ordinary input.

Changes:
- Match hooks and Raw Input in either order, retain device identity and replay only withheld events.
- Defer matched actions until outside the low-level hook callback.
- Treat a stopped ball as idle, and fail open only when blocked movement continues without raw motion.
- Replay other pointing devices during navigation regardless of raw/hook arrival order.
- Add core regressions for both event orders, duplicates, wheel axes, idle and actual stream loss.

Validation: the cloud workflow runs core checks, interface/version/release policy checks,
two executable builds, and live WebView2 verification before release upload.
See the associated Actions run for the final result.

Limitations and next work: no physical trackball signal can be generated by the cloud tests.
Verify orbit, Back-toggle pan and deliberate clockwise/anticlockwise circles on the owner's
M512 in Chamfer Studio after updating. Preserve existing per-device corrections and all
other saved programs. The M512's standard mouse input remains two-axis.
