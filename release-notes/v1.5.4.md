# Chamfer Trackball v1.5.4

2026-10-29

- Buttons renumbered: btn1 = top-left (Pan), btn2 = top-right (Orbit), btn3 = left click, btn4 = right click. btn1 + btn2 lit = zoom in / out. Your combinations move to the new numbers by themselves.
- The scroll wheels' names were the wrong way round — now Left and Right match the trackball — and the side wheel's up / down is no longer reversed.
- A wheel can now go to a program you pick: "Go to a program (up / down)" — turn up for one program, down for another.
- The guide can be minimized with its – button into a small bar (mode + four button lights); + opens it again.
