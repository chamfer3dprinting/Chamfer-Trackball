# Chamfer Trackball v1.2.4

2026-10-28

- Smoother changes between orbit, zoom and pan in 3D modelling: while you start a circle (zoom) or a shake (swap orbit/pan), the model now holds still instead of orbiting first, so the moves no longer fight each other. Ordinary rolling and wide arcs orbit exactly as before.
- Glide left over from orbit can no longer carry into pan or zoom after a change.
