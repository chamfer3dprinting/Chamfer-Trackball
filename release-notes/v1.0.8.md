# Chamfer Trackball v1.0.8

2026-10-28

- Programs: keep several complete setups, for example 3D modelling and Normal mouse, and switch between them like a DPI button: set a button to Next program, press your own keyboard shortcut, or pick one from the tray icon. A message shows which program is on.
- Ball gestures: set a button to Ball gestures, hold it, roll the ball in one of eight directions and let go to run that direction's shortcut, macro or action. A quick press is still a normal click.
- New Macros page: make as many macros as you like, each with any number of steps: shortcuts, typed text, waits, clicks and scrolls. Give them to a button or a gesture, and test them with one click.
- New on-screen indicator: while you orbit, pan or zoom, a small label next to the pointer shows what you're doing and which way you're rolling (Orbit ↗, Pan ←, Zoom in). It also shows the gesture you're drawing and what it will run, shortcuts and macros as they fire, and program changes. Turn it off in Buttons & keys → Extras.
- New Click tolerance on Speed & direction: stiff buttons can nudge the ball while you press them. Raise it so those presses still count as clicks instead of starting orbit or pan.
- Fixed: keyboard shortcuts on a button only worked inside 3D apps. Shortcuts, macros and gestures now work in every app.
- More keys can be recorded: Win, Backspace, punctuation, media and volume keys, and a modifier on its own such as Shift.
- Updates now come from one GitHub folder, like Chamfer3D Studio. The Admin app finds new versions without connecting GitHub; connecting is only needed to release for public.
