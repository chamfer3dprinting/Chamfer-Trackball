# Chamfer Trackball v1.0.0

2026-10-27

- First version of Chamfer Trackball for the Nulea M512.
- Hold Back + roll to orbit, hold Middle + roll to pan, left scroll wheel to zoom, tap Back to fit the view.
- Rotatrix-style keyboard control: hold Ctrl, Ctrl + Shift or Ctrl + Alt and roll.
- Works with Chamfer3D Studio, Fusion, Blender, Onshape, FreeCAD, Inventor, Rhino, SOLIDWORKS and Tinkercad.
