# Chamfer Trackball v1.0.1

2026-10-28

- New look based on the Chamfer3D logo, with Dark, Light, Match Windows and Custom themes.
- Change what every trackball button does: orbit, pan, zoom, fit view, a keyboard shortcut, or turn it off. Press a button on your trackball and it lights up in the list.
- Set the left and right scroll wheels to normal scroll, smooth zoom, reverse direction or off.
- Quick setups for buttons + keys, keyboard only (Rotatrix style) or buttons only.
- Updates install inside the app: click Update now and Chamfer Trackball downloads, installs and restarts itself.
- About page shows your version, update status and what's new in each version.
- The Try it pad only takes over the mouse while the pointer is over it, so the rest of the window works normally.
