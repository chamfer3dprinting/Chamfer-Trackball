# Chamfer Trackball v1.2.6

2026-10-29

- Orbit, Pan and Zoom hold keys can now be any keys you like: Ctrl, Shift, Alt and/or one other key, for example Space or Ctrl+Q. Press Set keys and press them. A quick tap of that key still types it.
- Each CAD app's own orbit, pan and zoom controls can be changed on the CAD apps page, so the ball moves the right thing in any app.
- Circles for zoom are easier: slower, relaxed circles count now, not only quick ones.
- The ball picture on Buttons & keys shows when the ball sees you drawing circles (↻ zoom in, ↺ zoom out), so you can check the sensor in any window.
