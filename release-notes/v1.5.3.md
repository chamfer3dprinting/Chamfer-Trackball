# Chamfer Trackball v1.5.3

2026-10-29

- btn1 and btn2 light up in the guide only while you're pressing them — no more staying blue after a click.
- btn3 (Pan) and btn4 (Orbit) are tapped on and off, never held: tap = on (lit), tap again = off. If yours were set to the hold versions they're switched to the tap versions.
- The guide's lights now always match what's really on, so a tap can't leave a button stuck lit.
- btn3 + btn4 zoom also works after you've been clicking with btn1 / btn2.
