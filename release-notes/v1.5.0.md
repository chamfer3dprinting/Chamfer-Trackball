# Chamfer Trackball v1.5.0

2026-10-29

- Buttons now light up by tapping: tap btn1, btn2, btn3 or btn4 and it stays lit in the guide; tap it again and it goes off. btn1 and btn2 still click in your app as normal.
- New: Combinations (Buttons & keys). Pick two or more buttons and a command — for example btn1 + btn3 = 3D Rotate, btn3 + btn4 = Snap view. When exactly those buttons are lit, the command runs: a mode stays on while they stay lit, a shortcut / Snap view / macro runs once.
- The guide shows the combination in use under the mode name.
