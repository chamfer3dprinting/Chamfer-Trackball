Circle zoom

Draw circles to zoomSelect the 3D modelling program and place the pointer over the 3D viewport. Roll straight to orbit or pan. Draw one small circle to start zooming: clockwise zooms in and anticlockwise zooms out. The first recognized loop already zooms; slightly uneven circles and brief pauses are accepted. Keep circling for continuous zoom; roll straight to return to navigation. This is enabled by default in the 3D modelling program.
Circle sizeIncrease this if your circles are larger; decrease it if broad curved orbits trigger zoom. Zoom speed uses Zoom sensitivity in Speed & direction.

This recognizes the shape of a roll, not physical ball twist. The Back button toggles orbit and pan; circle zoom works in both modes. Normal mouse stays unchanged in its separate program.

Program

Every setting on this page belongs to the program you pick here — each program has its own pointer speed, motion feel, 3D speeds, directions, precision and click tolerance. Switching program (button, shortcut or tray) switches them too.

Pointer speed / effective DPI

Software speed for the identified trackball. Lower is slower and more exact; higher travels farther. Saved with , so each program has its own. Default is your trackball's own DPI.

DPI
Trackball DPI keySelect the DPI set by the trackball’s physical DPI key. This calibrates the effective DPI estimate; software cannot change the sensor’s hardware DPI.

Applies to this trackball in Normal mouse, 3D modelling and added programs. Uses your Windows speed as the baseline; quitting restores native pointing. 3D movement uses the separate Orbit, Pan and Zoom speeds below.

Motion feel

Soft stop after releaseThe pointer and 3D view follow the ball directly, then ease to a stop after the ball stops. Glide sets the decay time. Turn this off to stop immediately. Clicking or releasing a navigation key stops glide.
Glide

The decay time for pointer movement and 3D navigation in this program. Short feels precise; long coasts farther.

3D speed

50 is the default (100%). The low end goes down to 1%; 0 stops that motion. These speeds affect 3D navigation, independently of pointer DPI and face switching.

Precision

Precise when rolling slowlySlow, small rolls move the model less (down to about a third), fast rolls stay full speed — so you can line up a view exactly and still spin it quickly.
Windows “Enhance pointer precision” is on. It speeds the pointer up when you roll fast, so the same roll turns the model by different amounts. For the most exact control, turn it off.

Tip: a higher DPI on the trackball (its DPI key) with lower Orbit/Pan speed here gives the finest control.

Button clicks

The M512's buttons are stiff, so pressing one can nudge the ball. This sets how much the ball may move while you press a button and it still counts as a click (or a quick tap like Fit view) instead of starting orbit, pan or a gesture.

Click tolerance

Clicks turning into orbit or pan by accident? Move it right. Orbit feels slow to start? Move it left.

Native integrations

Native integration gets the camera and the surface under your cursor. Mouse emulation provides orbit, pan and wheel zoom for other apps.

The required integration is included in this executable. The button installs it into that app's normal add-on folder.

Orbit, Pan and Zoom here are the app's own mouse controls, the ones Chamfer Trackball presses for you while you roll. If rolling moves the wrong thing in an app, match these to that app's settings.
